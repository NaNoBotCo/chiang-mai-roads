Stories

The long reads: what a road does to an old city, why the moat runs one way, the trees, the flood, the monk.

Survey of India Offices · Public domain

The site's spine. It takes every drivable way OpenStreetMap holds for the city and asks the same questions of the square inside the moat and of each ring outside it: how many intersections per square kilometre, how many lanes end in a dead end, how long a block is, how strongly the streets keep to a grid, how much of the network runs one way, how many wats sit in each zone. The measurements page has the numbers; this page reads them.
